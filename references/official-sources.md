# מקורות רשמיים ובדיקה בזמן העבודה

קישורים אלה הם נקודות התחלה; קרא את הדף העדכני בעת הצורך. הם אינם אישור שמידע חי נבדק כעת. השתמש רק בדומיין הרשמי ובהפניות רשמיות מתוכו. דומיין דומה בשם או עותק של דף ממשלתי אינו האתר הרשמי.

| צורך | מקור רשמי | מה לבדוק |
|---|---|---|
| N-600K | https://www.uscis.gov/n-600k | מהדורה, הוראות, אופן הגשה ואגרה כשהיא רלוונטית |
| הוראות N-600K | https://www.uscis.gov/sites/default/files/document/forms/n-600kinstr.pdf | דרישות המסמכים, תרגום, העדפת מקום ותאריך, השלמת ההליך |
| בירור חריג נקודתי | https://www.uscis.gov/policy-manual/volume-12-part-h-chapter-5 | INA 322 לפי נסיבה ממשית שעלתה |
| זמני טיפול | https://egov.uscis.gov/processing-times/ | טופס, לשכה, סוג מדד, תאריך והסתייגויות האתר |
| ESTA | https://esta.cbp.dhs.gov/ | תנאי שימוש, אישור אישי, דרכון, אגרה נוכחית בעת הצורך |
| ויזת ביקור | https://travel.state.gov/content/travel/en/us-visas/tourism-visit/visitor.html | חלופה מתאימה אם ESTA אינו מתאים |
| תעודת לידה בישראל | https://www.gov.il/he/service/birth_certificate | הפקה בעברית ובאנגלית |
| תעודת נישואין בישראל | https://www.gov.il/en/service/locate_marriage_certificate | איתור מסמך חסר |
| דרכון מתחת לגיל 16 | https://travel.state.gov/en/passports/apply/child/under-16.html | DS-11, ראיות, נוכחות הורים, חתימה ותשלום |
| טופסי דרכון | https://travel.state.gov/en/passports/apply/help/forms.html | הטופס המתאים והמהדורה הנוכחית |
| מוקד קבלת דרכונים | https://passportfacilitylocator.travel.state.gov/ | מוקד, שעות ואופן קביעת תור מול המוקד עצמו |
| SSN | https://www.ssa.gov/number-card | מספר ראשון, דרך הגשה ותיאום עם המשרד |
| SS-5 | https://www.ssa.gov/forms/ss-5.pdf | ראיות, גיל והתייצבות, מקור/עותק מוסמך, כתובת ושדות למילוי אנושי |

לכל קביעה שמשנה החלטה או פעולה, שמור: קישור, תאריך בדיקה, מה נאמר במקור, מה עדיין לא ידוע והשלכה מעשית. בדיקת חיפוש או כותרת אינה תחליף להוראות המלאות כשניגשים להגשה. אל תטען לאימות שהכלי לא הצליח לבצע.

אם אתר רשמי אינו נגיש, דווח על הפער במדויק והמשך בהכנות שאינן תלויות בו. אל תעביר מידע משפחתי לאתר חלופי ואל תעקוף חסימת גישה. בקש מהמשתמש מסמך או הודעה רשמיים שבידו אם הם דרושים. מידע ישן או ממקור משני עשוי לעזור להתמצאות בלבד; לא להחלטת הגשה, תשלום או קביעה של זמינות תורים.
