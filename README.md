# אזרחות אמריקאית לילדים במשפחה 🇺🇸

עוזר עבודה בעברית למשפחות שכבר מתקדמות במסלול N-600K: מיפוי מצב לכל ילד, מסמכים ותרגומים, בחירת לשכת USCIS, הכנת בקשה, נסיעה וראיון, ובהמשך תעודת אזרחות, דרכון ו־SSN.

המאגר מכיל הוראות ותבניות ריקות. אין בו תיקים משפחתיים, מסמכי ילדים או גישה אליהם. הוא אינו שירות ממשלתי, אינו מבטיח זכאות או תוצאה ואינו תחליף לייעוץ משפטי כשנדרש.

## שימוש 1: פשוט להעתיק ל־ChatGPT

לא צריך להתקין דבר או להשתמש בשורת פקודה:

1. פתחו את [CHATGPT-PROMPT.md](CHATGPT-PROMPT.md).
2. העתיקו את כל תוכן הקובץ. ב־GitHub אפשר להשתמש בתצוגת Raw כדי להעתיק את הטקסט ללא רכיבי האתר.
3. פתחו שיחה חדשה ב־ChatGPT והדביקו את הטקסט כהודעה הראשונה.
4. ספרו בקצרה מה השלב של כל ילד, בכינויים, ומה תרצו לקדם עכשיו. אין צורך למסור שמות מלאים או מספרי מסמכים כדי להתחיל.

ההודעה עצמאית: רצף העבודה, מבנה המעקב, תבנית הכנת הבקשה ומפת המקורות כבר כלולים בה. הגלישה, העלאת הקבצים, השמירה והתזכורות תלויות בכלים הזמינים בחשבון ובשיחה. בלי גלישה צריך להביא את המידע הרשמי העדכני; בלי כלי שמירה משתמשים בסיכום להעתקה.

הדבקת הטקסט אינה מתקינה סקיל בחשבון, אינה מחברת חשבונות ואינה מגישה דבר. אין להניח ששיחה חדשה מכירה את השיחות הקודמות.

## שימוש 2: התקנת סקיל בסוכן שתומך בכך

למי שמשתמש בכלי תואם כמו Codex או Claude Code ויש לו Node.js ו־npx זמינים:

```sh
npx skills add MosheHM/family-n600k-skill
```

בחרו במתקין את הסוכן ואת היקף ההתקנה הרצויים. אפשר לבדוק מה מזוהה במאגר בלי להתקין:

```sh
npx skills add MosheHM/family-n600k-skill --list
```

שם הסקיל הוא `manage-family-n600k`. לאחר ההתקנה בקשו מהסוכן להשתמש בו כדי למפות את שלבי הילדים ולהציע צעדים מעשיים להמשך. דרך ההפעלה המדויקת תלויה בסוכן.

פקודת `--list` בודקת גילוי של סקילים במאגר; היא אינה מתקינה את הסקיל ואינה בודקת את התנהגותו בסוכן.

התקנת CLI מיועדת לסוכנים תואמים; לשימוש בשיחת ChatGPT רגילה השתמשו במסלול ההעתקה שלמעלה.

## מאגר אחד, עדכונים במקום אחד

- ההוראות המשותפות נשמרות ב־`SKILL.md`, ב־`references/` וב־`assets/`.
- `CHATGPT-PROMPT.md` נוצר מההוראות האלה ומכיל גם הוראות לשיחה ללא כלים. הוא נשמר במאגר כדי שאפשר יהיה להעתיקו ללא התקנה.
- התקנות קיימות אינן מתעדכנות רק משום שהמאגר השתנה. לעדכון הסקיל הריצו:

```sh
npx skills update manage-family-n600k
```

- בשיחת ChatGPT יש להעתיק מחדש את `CHATGPT-PROMPT.md` המעודכן, ולהעביר באופן פרטי את סיכום התיק. טקסט שכבר הודבק ושיחות קודמות אינם מתעדכנים אוטומטית.
- סקיל שהותקן בדרך אחרת מתעדכן לפי המנגנון של אותה מערכת; המאגר אינו מסנכרן מעצמו התקנות נפרדות.

למתחזקים, לאחר שינוי תוכן ההנחיות:

```sh
python3 scripts/build_chatgpt_prompt.py
python3 scripts/build_chatgpt_prompt.py --check
python3 scripts/validate_distribution.py
```

עברו גם על הטקסט שנוצר לפני פרסום. הסקריפטים משתמשים בספרייה הסטנדרטית של Python בלבד, ללא גישה לרשת.

## מה העוזר עושה

- ממשיך מהשלב הנוכחי של כל ילד ושומר הפרדה בין אחים ומשקי בית.
- משתמש בתיק המשפחתי הקיים כנקודת מוצא תפעולית, בלי לפתוח מחדש סקירת זכאות כללית. סתירה מהותית או גיל קריטי נבדקים נקודתית.
- מסייע ברשימת מסמכים, טיוטות תרגום והכנת בקשה לבדיקה אנושית. אינו מוסיף נוטריון או אפוסטיל כחובת ברירת מחדל.
- עוזר לבחור לשכה לפני ההגשה, כששינוי מאוחר יותר עלול להיות מורכב. זמני טיפול אינם תורים פנויים או הבטחה.
- מתכנן גם את שלבי הדרכון וה־SSN. מומלץ להיערך לבקשת SSN במהלך הביקור בארה״ב ולכתובת אמריקאית אמינה לקבלת דואר, בהסכמת בעל הכתובת ובהתאם להנחיות SSA העדכניות.
- מבחין בין זימון, ראיון, השלמת אזרחות וקבלת התעודה. זימון לראיון אינו מעניק אזרחות.

## פרטיות ואישור אנושי

אל תעלו למאגר, ל־Issues או ל־Pull Requests שמות ילדים, תאריכי לידה, דרכונים, תעודות, מספרי תיק, כתובות פרטיות, מספרי SSN, סיסמאות, פרטי תשלום או קישורים למסמכים פרטיים. לשיתוף שיפור השתמשו בתיאור כללי ובדוגמאות מומצאות בלבד.

תבניות שמולאו שייכות למרחב פרטי שהמשפחה אישרה, מחוץ למאגר. אין הרשאה אוטומטית להעביר תיק בין קרובים. לפני שיתוף מידע, הגשה, תשלום, חתימה או הצהרה יש לבדוק את הפעולה, היעד וההרשאות ולקבל את האישור הנדרש. פעולות שהמערכת מחייבת לבצע אישית נשארות בידי האדם. אין הגשה או תשלום עצמאיים ברקע.

הכלי עשוי לטעות. דרישות משתנות נבדקות במקורות הרשמיים בזמן העבודה; אין במאגר אגרות, הבטחות זמני טיפול או זמינות תורים קבועות.

## הקבצים

- `SKILL.md` — ההוראות הראשיות לסוכן, עם שם ותיאור לזיהוי.
- `references/workflow.md` — רצף העבודה לפי שלבים.
- `references/official-sources.md` — מקורות ממשלתיים לאימות בזמן העבודה.
- `assets/` — תבניות ריקות למצב התיק, רשימת מסמכים וטיוטת הכנת בקשה, ואייקון.
- `agents/openai.yaml` — מטא־נתונים לסוכנים שתומכים בהם.
- `CHATGPT-PROMPT.md` — ההודעה העצמאית להעתקה.
- `scripts/` — יצירת ההודעה ובדיקות מבנה וסנכרון.
